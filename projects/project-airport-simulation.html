Simulación de Aeropuerto

Simulación 2024
Python SimPy Pandas

Descripción

Sistema de simulación completo para modelar operaciones aeroportuarias, incluyendo gestión de pistas, asignación de gates y optimización de tiempos de espera. Este proyecto implementa un modelo de eventos discretos para simular el flujo de aeronaves en un aeropuerto.

Características Principales

  • Simulación de llegadas y salidas de vuelos
  • Gestión dinámica de pistas de aterrizaje y despegue
  • Asignación optimizada de gates
  • Análisis de tiempos de espera y cuellos de botella
  • Visualización de métricas de rendimiento

Tecnologías Utilizadas

El proyecto está desarrollado en Python utilizando la biblioteca SimPy para la simulación de eventos discretos, y Pandas para el análisis y procesamiento de datos.

Resultados

La simulación permite identificar puntos de congestión en las operaciones aeroportuarias y evaluar diferentes estrategias de optimización para mejorar la eficiencia operativa.
